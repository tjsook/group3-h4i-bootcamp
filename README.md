## Overview

### Purpose

We are designing an app for an unnamed coffee shop with functionality to view orders, order drinks, and contact the store for inquiries. Within the home page, you are able to see the title, logo, and name, a preview of the order page, and the best-selling drink right now. It will also house the About Us page.
The contact form will have fields for name, phone#, email, address (optional), the message field, and a submit button.
The order page will be our first custom page, consisting of: an object called "order" (`order(drink_id , user_id , size , type_of_milk , item, item_type)`), the menu, individual items (with item desc, prices, image, size/milk type), a checkout (with payment methods, add to cart, remove from cart), and an organized page by category. 
Finally, we will have an Account info page with information of the user, payment info, order history, delete/switch/logout of account, and an option to update account information.
